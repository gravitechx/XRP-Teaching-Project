# Instructions
**To view these in markdown, click on the window with a magnifying glass or use `ctrl + k v`**


## Navigating to Practice Problems
**VERY IMPORTANT!**

Make sure you have switched to the correct branch before writing code!
1. Use `ctrl+shift+p` 
2. Type `git: Checkout to` 
3. Click on your branch name (EX: `NC`)

## Practice Problems
* You will find your practice problems in files labeled by week
* In each file you will have `// TODO` comments that will give you specific instructions.
* You can also find these `TODO` comments using the `PROBLEMS` tab in the lower window (next to `OUTPUT`)

## Checking Practice Problems
Make sure you follow all `TODO` comments about uncommenting lines of code **first.**

* Use `ctrl+shift+p`
* Type `Test Robot Code` (select the one called `WPILIB: Test Robot Code`)
* Once the practice tests have been run, look at the `TERMINAL` tab (in the lower window between `DEBUG CONSOLE` and `PORTS`)
* If you get `BUILD SUCCESSFUL` in the console, you completed the practice OR didn't uncomment all the practice tests for your week
* If you get `BUILD UNSUCCESSFUL` then you didn't finish completely
  * Above the message, there should be an indication of what tests have been passed and failed
  * EX: `Week1 > onlyTest() PASSED`
  * Use this to figure out which practice problem(s) you didn't complete

## Submitting Practice Problems (Pushing to Github)
1. Go to the Source Control Tab (Usually under the search tab)
2. Add each file to the staged changes
3. Write a commit message (EX: "Finished Week1 practice")
4. Click `commit`
5. Click `sync changes` or use `ctrl+shift+p` then `git: push` 
    * This will actually send your changes to Github (online repository)
